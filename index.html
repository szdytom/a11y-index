      这一页自己是怎么做的

      清单讲无障碍，页面本身也是无障碍的。几个具体做法：

      • 语义结构：跳转链接、header / nav / main / aside / footer 地标、h1–h3 层级连续，结果是一个真正的列表。
      • 键盘可用：Tab 顺序即视觉顺序；焦点环 3px 实线加偏移，从不用 outline: none 抹掉。
      • 对比度：正文与背景对比度均 ≥ 7:1，次级文字 ≥ 4.5:1，界面上限标签 ≥ 4.5:1。
      • 状态可感知：筛选结果数用 role="status" 播报；0 结果时给出下一步怎么做，而不是只说“空”。
      • 判断有依据：星标、语言、许可证、是否停更全部标在卡片上，正文里说“酷”的地方都写清了为什么。
      • 尊重偏好：prefers-reduced-motion 关掉全部过渡；forced-colors 下改用系统颜色与边框；prefers-contrast: more 下文字与边框加重。
      • 不依赖颜色：星标、语言、许可证都有文字标签，色块只做辅助。
      • 触控目标：所有可点元素最小 44×44 CSS 像素。
