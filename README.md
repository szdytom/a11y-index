# 很酷的无障碍开源项目

一份中文策展清单：2026 年仍然活跃、而且**看起来真的很酷**的无障碍（a11y）开源项目。

**在线访问：<https://szdytom.github.io/a11y-index/>**

交付物是一个自包含的静态页面。它自己就是一个无障碍示范品——讲无障碍的页面，
如果自己不合格，那这份清单就没有说服力。

---

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面本体。语义结构、地标、跳转链接都在这里。 |
| `style.css` | 视觉方向「盲道」的全部实现，含深色模式与三种偏好适配。 |
| `app.js` | 筛选 / 搜索 / 排序，以及页头那块读取真实系统偏好的「环境信号台」。 |
| `data.json` | **唯一数据源**。清单内容全部在这里，机读。 |
| `data.js` | 由 `build.py` 从 `data.json` 生成，供页面直接引用（`file://` 下无法 fetch JSON）。 |
| `build.py` | `data.json` → `data.js`，同时做数据健全性检查。 |
| `a11y_check.py` | 静态无障碍自检（结构、焦点、偏好适配、动态控件可访问名称）。 |
| `tools_contrast.py` | 校验配色方案的 WCAG 对比度。 |
| `parse_spill.py` | 从抓取记录里解析出仓库原始数据，生成 `github_raw.json`。 |
| `.nojekyll` | 让 GitHub Pages 跳过 Jekyll 处理，按原样发布静态文件。 |

## 运行

页面不需要构建、不需要服务器、没有依赖：

```bash
# 直接打开
xdg-open index.html        # 或双击

# 或在本地起一个 http 服务
python3 -m http.server 8000
```

改了清单内容后重新生成一次：

```bash
python3 build.py           # data.json -> data.js
```

## 自检

```bash
python3 a11y_check.py      # 结构 / 焦点 / 偏好适配 / 动态控件可访问名称
python3 tools_contrast.py  # 浅色与深色两套配色的对比度
```

`a11y_check.py` 刻意**不做**"全自动通过 WCAG"的承诺：能静态判定的只是一部分规则，
它防的是低级错误，不替代真人走查。脚本结尾会打印仍需人工验证的项。

## 设计说明

视觉方向叫**盲道**。选择理由很直接：盲道是"无障碍"这个概念里最有实体感、
最容易被认出来的东西，而它本身就是一套颜色 + 形状的编码系统。

- **分类标记用真实六点制盲文**（a–j），点阵位置严格对应点 1–6，不是随手画的装饰。
  侧栏有图例说明，屏幕阅读器会跳过这些图形（`aria-hidden`），分类名另有文字。
- **黄色只做色块，不做小字**。`#E9A800` 上的墨色文字对比度 8.31:1，
  但黄色小字在白底上不达标——所以它只用来铺底、做引导块和强调条。
- **页头那块「环境信号台」是这套设计里唯一一次冒险**：它实时读取你系统的
  `prefers-color-scheme`、`prefers-reduced-motion`、`prefers-contrast`、
  `forced-colors`、指针类型，以及你此刻是用键盘还是鼠标。改一下系统设置，
  它立刻跟着变——把"无障碍不是开关而是环境"这件事直接演示出来。

## 无障碍实现要点

- 语义结构：跳转链接、`header/nav/main/aside/footer` 地标、`h1–h3` 层级连续、结果是真列表。
- 键盘：Tab 顺序即视觉顺序，无正数 `tabindex`；焦点环 3px 实线加偏移，从不用 `outline:none` 抹掉。
- 对比度：正文 ≥ 7:1，次级文字与标签 ≥ 4.5:1，浅色模式最差 6.37:1，深色最差 7.62:1。
- 不依赖颜色：星标、语言、许可证、推荐/新/停更全部有文字标签，色块只做辅助。
- 状态可感知：结果数走 `role="status" aria-live="polite"`；0 结果给出下一步操作。
- 触控目标：所有可点元素最小 44×44 CSS 像素。
- 偏好适配：`prefers-reduced-motion` 关闭全部过渡；`forced-colors` 下改用系统颜色；
  `prefers-contrast: more` 加重文字与边框；`prefers-color-scheme: dark` 独立配色。
- 无追踪、无外链字体、无第三方脚本、无外部图片（favicon 是内联 SVG）。
- 关闭 JavaScript 时给出明确说明，并指向 `data.json`，不留空白页。

### 验收记录（2026-10-11）

在 Chromium 里实际跑过，不是只看代码：

| 项目 | 结果 |
| --- | --- |
| 控制台报错 | 0 |
| 卡片 / 分类 / 图例数量 | 76 / 10 / 10，与 `data.json` 一致 |
| 外链 `rel=noopener` | 117 / 117 |
| 悬空锚点、缺 alt 图片 | 0 |
| 正数 `tabindex` | 0 |
| 键盘焦点环 | 3px solid，实测生效 |
| 筛选 / 搜索 / 空态 / 重置 | 逐项通过 |
| 深色、强制颜色、更高对比度、减弱动效 | 四种均生效，信号台文字同步更新 |
| 390×800 重排 | 无横向滚动、无元素溢出 |
| 对比度 | 浅色最差 6.37:1，深色最差 7.62:1 |

过程中修掉的两个真实缺陷：

1. **卡片元数据里的「官网」链接点不动**——标题上的整卡点击覆盖层盖住了它。
   键盘能 Tab 到、鼠标点不到，属于典型"只看代码发现不了"的问题。
   已把 `.card__meta` 抬到覆盖层之上，41 个链接逐一复测通过。
2. **强制颜色模式下分类胶囊文字消失**——给选中态铺 `Highlight` 背景撞上了
   浏览器对背景色的强制映射。改为用「边框加粗 + 字重」表达选中态，
   不依赖颜色，也不再触发该渲染问题。

仍未自动验证、需要真人确认的：屏幕阅读器实际朗读效果、200% 文字缩放下的阅读体验。

## 数据说明

77 个项目，分 10 类，其中 29 个标为「推荐」，11 个标为「停更」。

星标数与最近推送时间为 **2026-10-11** 的 GitHub 公开 API 快照，会随时间变化。
许可证以仓库自身标注为准，商用前请自行复核。

本机无法直连 `api.github.com`，四路研究分别经由只读镜像
（`repos.ecosyste.ms`、`gh-proxy.com`、`gh-api.p3terx.com`）获取 GitHub REST API
原样返回的字段；另有 35 个仓库由本仓库直接抓取的原始 JSON 交叉核对
（见 `github_raw.json`，可用 `parse_spill.py` 重新解析）。非 GitHub 项目
（WhoCanUse、Inclusive Components、e-NABLE、Open Bionics 等）只有官方链接，无星标数据。

已知存在元数据冲突的项目：**Subtitle Edit** 的 API 许可证字段是 MIT，
但仓库内 `LICENSE` 为 GPL-3.0，卡片上已注明。
